# Скрипты обновления агентов на Ubuntu / Linux (Workstation Manager)

Данная директория содержит независимые скрипты для запуска обновления Windows-агентов **прямо с сервера под управлением Ubuntu / Debian / Linux**:
- **`update-mnok.sh`** (или `python3 update_mnok.py`) — для всех 37 рабочих станций **МНОК** (пароль `oitp507`).
- **`update-ck.sh`** (или `python3 update_ck.py`) — для всех 19 рабочих станций **ЦК** (пароль `bmstu023`).

Скрипты полностью автономны: в них уже вшиты группы, токены, IP-адреса, логины и пароли администраторов, а также двухфакторная проверка резервных паролей.

---

## 1. Быстрый старт на Ubuntu

### Шаг 1. Перейдите в папку со скриптами
```bash
cd /path/to/dash/scripts/ubuntu
```

### Шаг 2. Сделайте bash-скрипты исполняемыми (при необходимости)
```bash
chmod +x update-mnok.sh update-ck.sh update_mnok.py update_ck.py
```

### Шаг 3. Запуск интерактивного меню
Для **МНОК**:
```bash
./update-mnok.sh
# или
python3 update_mnok.py
```

Для **ЦК**:
```bash
./update-ck.sh
# или
python3 update_ck.py
```

## 2. Необходимые утилиты на Ubuntu для удаленного выполнения

Для удаленного запуска задач на Windows-компьютерах с Linux используется пакет **`impacket`** (`atexec.py` / `wmiexec.py` / `smbexec.py`) либо **`pywinrm`**.

Если пакет еще не установлен на вашей Ubuntu, скрипт при первом запуске **предложит установить его автоматически в 1 клик**, либо вы можете установить его заранее:

```bash
# Вариант А: через стандартный apt (рекомендуется)
sudo apt update && sudo apt install -y python3-impacket

# Вариант Б: через pip
pip3 install impacket pywinrm
```

## 3. Режимы работы (CLI-аргументы)

Скрипты можно запускать как интерактивно (с цветным меню), так и передавать флаги командной строки для автоматизации (например, по cron):

| Флаг | Описание | Пример |
|------|----------|--------|
| *(без флагов)* | Интерактивное цветное меню с выбором действий | `./update-mnok.sh` |
| `-a`, `--all` | Немедленно обновить все ПК корпуса подряд | `./update-mnok.sh -a` |
| `-p`, `--ping` | Быстрая проверка связи (ICMP + порты 135, 445, 5985, 3389) | `./update-mnok.sh -p` |
| `-w`, `--wol` | Отправить Wake-on-LAN пакеты для пробуждения ПК | `./update-mnok.sh -w` |
| `-i`, `--install` | Установить системные зависимости (`impacket`) | `./update-mnok.sh -i` |
